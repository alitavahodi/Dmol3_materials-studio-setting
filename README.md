# Boron Nitride Nanotubes for Genistein Drug Delivery

## Overview

This repository contains computational analysis and supporting scripts
related to the study of boron nitride nanotubes (BNNTs) as potential
nanocarriers for genistein.

## Research Context

The project investigates the interaction between genistein and
functionalized BNNT systems using density functional theory (DFT).

## Systems Studied

- (5,5) BNNT
- (6,6) BNNT
- (7,7) BNNT
- Fe-doped BNNT systems
- Genistein-loaded systems

## Computational Methods

- Density Functional Theory (DFT)
- PBE-GGA
- DNP basis set
- Spin-unrestricted calculations
- Mulliken analysis
- Hirshfeld analysis
- Fukui function analysis

## Software

- BIOVIA Materials Studio
- DMol³
- Python
